# Mi Asistente de Ubicación (PWA)
Geolocalización + Leaflet/OpenStreetMap + cámara (getUserMedia) + IndexedDB. Sin dependencias ni build (Leaflet 1.9.4 incluido en /lib).
## Ejecutar
- Local: `python -m http.server 8080` y abrir http://localhost:8080 (localhost cuenta como contexto seguro).
- En el teléfono se requiere HTTPS: súbelo a GitHub Pages / Netlify / Vercel y abre la URL.
